# Controle de Entrega de Ferramentas - Viana e Moura

Sistema web desenvolvido para controle de entrega e devolução de ferramentas.

## Funcionalidades

- Cadastro de pessoas
- Cadastro de grupos
- Controle de entrega de ferramentas
- Controle de devolução
- Salvamento automático no navegador
- Exportação da tabela em PDF
- Interface responsiva
- Organização por categoria e etapa

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- jsPDF

## Como utilizar

1. Cadastre as pessoas
2. Cadastre os grupos
3. Preencha o formulário
4. Clique em "Adicionar"
5. Gere o PDF quando desejar
